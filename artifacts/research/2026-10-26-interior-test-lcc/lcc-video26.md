# [Video Reconstruction](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#video-reconstruction)

LCC Studio supports 3DGS reconstruction from video input. Upload a single video, and LCC Studio automatically extracts frames, estimates camera poses, and reconstructs a 3D model — no structured multi\-angle photo capture required.
![Video input type](https://cdn-bukbb1.xgrids.cloud/xgrids-docs/assets/v200-video-input-DpsdByeE.png)

Selecting the Video input type in New Scene

## [Supported Video Formats](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#supported-video-formats)

| Item | Supported Range |
|---|---|
| File format | mp4, mov, webm |
| Video duration | Up to ~16 minutes \(1000 seconds\) |
| Video resolution | 720p – 4K \(per side 720px–4090px\) |
| Video codec | H.264, H.265, AV1, VP9 |

> 

Note: avi, mkv, and similar formats are not supported. Panoramic videos and distorted images are also not supported. If a video does not meet the conditions above, the interface shows a red prompt and blocks reconstruction.

## [Workflow](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#workflow)
1. Click Generate Now → Video Reconstruction.
2. Click to select the video file. LCC Studio automatically validates format, duration, resolution, and codec.
![Video validation result](https://cdn-bukbb1.xgrids.cloud/xgrids-docs/assets/v200-video-validation-BEswK2fe.png)

Video validation result \(duration, resolution, codec\)
1. 

Set the sampling frame rate \(frame extraction density\):
  - **1 frame/sec**: suits longer videos \(over 250 seconds\).
  - **2 frames/sec**: suits medium\-length videos \(within 250 seconds\).
  - **4 frames/sec**: suits short videos \(within 250 seconds\), with richer detail.
2. 

Set the other reconstruction parameters \(reconstruction quality, maximum Gaussian points, etc., same as standard reconstruction\).
3. 

Click Start Reconstruction.

> 

Note: The longer the video, the fewer frame rate tiers available. Videos over 500 seconds can only use 1 frame/sec; videos over 250 seconds cannot use 4 frames/sec \(the corresponding tier is grayed out automatically\).

## [Capture Recommendations](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#capture-recommendations)

For the best reconstruction results, follow these capture guidelines:

| Recommended | Description |
|---|---|
| ✅ Orbit the subject | Move slowly around the target object or space, covering multiple angles. |
| ✅ Move slowly | Keep movement speed at 0.5–1 meter per second. |
| ✅ Stay continuous | A single continuous video works best; avoid frequent pauses. |
| ✅ Even lighting | Avoid dramatic lighting changes. |

| Avoid | Description |
|---|---|
| ❌ Fixed viewpoint | A purely static shot cannot be reconstructed; LCC Studio reports failure. |
| ❌ Fast movement | Over 2 meters per second may cause reconstruction failure or blur. |
| ❌ Spliced clips | An edited, spliced video reconstructs only the continuous portions; discontinuous portions are skipped. |

## [Image Sequence Reconstruction](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#image-sequence-reconstruction)

v2.2.0 adds image sequence reconstruction. In addition to video input, you can also perform 3DGS model reconstruction directly from a local image folder, suitable for scenarios where multi\-view images are already available.

### [Supported Image Formats](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#supported-image-formats)

| Item | Supported Range |
|---|---|
| File format | JPG, JPEG, PNG |
| Number of images | 50 – 1,000 |
| Image resolution | Up to 4090px per side |
| Resolution consistency | All images must have the same resolution |

> 

Note: TIFF, BMP, RAW, and similar formats are not supported. If images do not meet the requirements, the interface shows a red prompt and blocks reconstruction.

### [Workflow](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#workflow-1)
1. Click Generate Now → Video Reconstruction.
2. Select "Image Sequence" as the input type.
3. Select the folder containing images. LCC Studio automatically validates format, quantity, and resolution.
4. Set reconstruction parameters \(reconstruction quality, maximum Gaussian points, etc., same as video reconstruction\).
5. Click Start Reconstruction.
![Image Sequence Input](https://cdn-bukbb1.xgrids.cloud/xgrids-docs/assets/v220-image-sequence-input-vY39Eyd7.png)

Image sequence input interface

### [Capture Recommendations](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#capture-recommendations-1)

For the best image sequence reconstruction results, follow these guidelines:

| Recommended | Description |
|---|---|
| ✅ Multi\-angle coverage | Shoot around the target, taking a photo every 10°–15° |
| ✅ Sufficient overlap | Adjacent images should have ≥ 60% overlapping area |
| ✅ Consistent lighting | Complete shooting in a short time frame to avoid lighting changes |
| ✅ Sharp focus | Ensure every image is in focus; avoid motion blur |
| ✅ Appropriate image count | Small/medium objects: 100–300 images; large scenes: 500–1,000 images |

| Avoid | Description |
|---|---|
| ❌ Too few images | Fewer than 50 images will fail to reconstruct |
| ❌ Single viewpoint | Shooting from only one direction cannot recover complete geometry |
| ❌ Many blurry images | Blurry images degrade reconstruction quality; remove them beforehand |

> 

Note: The 1,000\-image upper limit for image sequence reconstruction aligns with the video frame extraction limit, balancing reconstruction quality and computational resources.

## [Reconstruction Report](https://docs.xgrids.com/en-us/06-lixel-cybercolor/01-lcc-studio/latest/16-video-reconstruction.html#reconstruction-report)

After video reconstruction / image sequence reconstruction completes, the report shows the following specific information:

**Video Reconstruction Report:**
- Reconstruction type: Video Reconstruction
- Video length
- Sampling frame rate
- Source video codec and resolution
- Source video format

**Image Sequence Reconstruction Report:**
- Reconstruction type: Image Sequence Reconstruction
- Number of images
- Image resolution
- Valid image ratio
