# 分享与导出
![](https://global.featurebase-attachments.com/c/static/019b2153-d554-76c0-bf97-bb19fe402e52/az7nr2bhw2.png)

作者 Aholo3d

最后更新 7 个月前

完成 3DGS 模型编辑后，你可以通过多种方式进行分享或导出，用于展示、传播或进一步使用。

# 一、在线分享

通过链接分享，是最简单、快速的项目分享方式。

### **1. 生成分享链接**
- 

点击「分享」按钮
- 

系统将生成一个项目链接

### **2. 发送链接**
- 

复制链接并发送给他人
- 

对方即可在线查看项目
![](https://693fd4b87538cac47acbde8f.featurebase-attachments.com/c/article/69ccb7548a6abc10bfcce1fa/019d47b3-3954-7fa2-a8a4-12c829947e7b/b64u-5YiG5LqrLnBuZw.png?X-Amz-Expires=3600&X-Amz-Date=20261026T160000Z&X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=DO801TYC4FCVNNEKURKM%2F20261026%2Ffra1%2Fs3%2Faws4_request&X-Amz-SignedHeaders=host&X-Amz-Signature=afbc491a43096850dbed9162e35c7d472b183ef354ba3c3ef7a056847f3dc1bf)
点击“分享”\-复制链接

# 二、导出视频

你可以将 3D 模型导出为视频，用于社交媒体或演示。

### **支持格式**
- 

MP4 视频

### **使用方式**
- 

在编辑器中点击「视频」
- 

设置镜头路径与效果
- 

导出视频

详细步骤请参考：[**视频导出指南**](https://aholo.featurebase.app/zh-CN/help/articles/4974221)
![](https://693fd4b87538cac47acbde8f.featurebase-attachments.com/c/article/69ccb7548a6abc10bfcce1fa/019d47ad-a422-72ec-8646-c59ab10d4664/b64u-5a6M5pW06KeG6aKR5Yqo5Zu-LmdpZg.gif?X-Amz-Expires=3600&X-Amz-Date=20261026T160000Z&X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=DO801TYC4FCVNNEKURKM%2F20261026%2Ffra1%2Fs3%2Faws4_request&X-Amz-SignedHeaders=host&X-Amz-Signature=98daec93d0c3d4b4bc3120e3019fd27cc2f689c804e00dc8fe0348a823d2ba14)
视频示例

# 三、下载点云文件

你可以导出点云数据，用于进一步编辑或开发。

### **支持格式**
- 

**PLY（高斯点云）**
- 

**SPZ（高斯点云）**

### **使用场景**
- 

导入到 Unity 等工具中使用
- 

进行二次开发或渲染
- 

用于专业项目
![](https://693fd4b87538cac47acbde8f.featurebase-attachments.com/c/article/69ccb7548a6abc10bfcce1fa/019d47b7-873b-783d-bea8-8505561c8af0/b64u-cGx5c3B65a-85Ye6LnBuZw.png?X-Amz-Expires=3600&X-Amz-Date=20261026T160000Z&X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=DO801TYC4FCVNNEKURKM%2F20261026%2Ffra1%2Fs3%2Faws4_request&X-Amz-SignedHeaders=host&X-Amz-Signature=36a8cd8b99b277a0e5875703783f192b420747f81a03b2c4ca306312eeae437f)
导出 PLY 或 SPZ 点云文件

# 四、截图

你可以将当前视角保存为图片。

### **使用方式**
- 

调整到目标视角
- 

点击「截图」

### **特点**
- 

快速导出
- 

保留当前构图
- 

适合用于封面或分享
![](https://693fd4b87538cac47acbde8f.featurebase-attachments.com/c/article/69ccb7548a6abc10bfcce1fa/019d47b6-dcfe-70b1-990f-4520d20dec7d/b64u-5oiq5Zu-LnBuZw.png?X-Amz-Expires=3600&X-Amz-Date=20261026T160000Z&X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=DO801TYC4FCVNNEKURKM%2F20261026%2Ffra1%2Fs3%2Faws4_request&X-Amz-SignedHeaders=host&X-Amz-Signature=8de310acea2c68b7001ae6018feda4330179514bc5c96856c49d47ab65cdf588)
导出截图

# 五、如何选择导出方式

你可以根据不同需求选择：

| **需求** | **推荐方式** |
|---|---|
| 分享给他人查看 | 在线链接 |
| 社交媒体传播 | 视频 |
| 快速展示画面 | 截图 |
| 进一步开发 / 编辑 | 点云文件（PLY / SPZ） |
