# Postshot User Guide

### Welcome to Postshot\!

Generating new images from a video or a set of photos has long been a goal of computer vision research. Recent advances in machine learning and neural rendering have finally made this goal a practical reality. We can now reconstruct the scene captured by the camera and render photorealistic images from new perspectives, using different lenses, focal\-lengths, fields\-of\-view, crop and compose the scene in 3D, animate new camera trajectories and more.

Postshot offers an end\-to\-end solution for tracking, training, editing and rendering radiance fields within a user\-friendly, seamless workflow. Explore the world of radiance fields and bring it to production.

## Feedback

Your feedback is much appreciated. Please send your questions and feedback via email to [support@jawset.com](mailto:support@jawset.com).

Reporting Bugs

Please always include the following information with your bug report:
- A description of how to reproduce the problem
- The Postshot.log file from the folder %LOCALAPPDATA%\\Postshot
- If the problem occurred during training, please provide the input images or video if possible.
- If you got an 'OUCH\! Postshot has crashed' error message, please include the latest crash dump from the folder %LOCALAPPDATA%\\Postshot\\CrashDumps.

### Release and Pre\-Release Builds

Postshot builds are available in two tiers.

**Release Builds** are available from the main download links on [https://jawset.com](https://jawset.com/) as well as through the in\-app menu 'Help/Check for Updates...'. These are more stable builds released at longer intervals. The user\-guide is updated to reflect the functions in Release Builds.

**Pre\-Release Builds** are available at [https://www.jawset.com/builds/postshot/windows/](https://www.jawset.com/builds/postshot/windows/). These builds are updated regularly. They represent the most recent development stage but typically are less stable. New functionality is usually not documented in the user\-guide yet.
