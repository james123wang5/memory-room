# OOOSplat 0.7.0

[中文](https://github.com/ooolabdev/ooosplat/releases#%E4%B8%AD%E6%96%87) \| [English](https://github.com/ooolabdev/ooosplat/releases#english)

## 中文

OOOSplat 0.7.0 加入全景视频与图片生成、外部模型导入、多格式导出、水平 WASD 漫游和自动定位视角，并改进图片匹配、生成进度与相机控制。

### ✨ 主要更新

#### 全景视频与图片生成
- 支持已拼接、单目、完整 360°×180°、2:1 ERP 全景 MP4。 
- 支持全景图片文件夹：至少两张同尺寸 JPG、JPEG 或 PNG。 
- 自动检测素材类型；无法确定时，在素材输入框内选择普通或全景类型。 
- 保留完整全景画面进行相机重建，仅将已注册画面转换为六面训练图片。 
- 全景使用独立训练配方，自动优化关闭时，快速／均衡／精细的 Splat 上限分别为100万／200万／300万；开启后根据档位和显存确定，最高允许1,000万。 

Splat 上限不代表最终点数，也不保证显存足够。首版不支持双鱼眼、双目、VR180、裁切全景、厂商私有原片及全景高清补拍。

#### 外部模型导入
- 在“已完成”分组点击“导入”，选择模型文件或文件夹。 
- 支持标准／压缩 PLY、SOG、SPZ、SPLAT 和 KSPLAT。 
- 自动识别关联的 COLMAP 数据，满足条件时可创建高清补拍任务。 
- 导入后可使用现有预览、编辑和导出功能。 
- 外部文件保持只读，删除导入项目不会删除外部原文件。 

不支持仅包含 COLMAP 的项目、普通点云 PLY、2DGS、LCC/LCC2 或 Streamed SOG。

#### 多格式导出
- “导出”菜单直接提供标准 PLY、压缩 PLY、SPZ v4 和单文件 SOG。 
- 每种格式附带简短说明，点击后直接启动，无需第二次选择格式。 
- 移除完整中转 PLY，按需处理删除、裁切、变换和 SH 旋转。 
- 导出弹窗显示进度、结果大小和文件位置，支持取消与失败重试。 
- 支持横竖屏视频和单文件离线 HTML。 
- 原始 `final.ply` 不变，失败或取消时保留已有导出。 

SOG、SPZ 通常更小，实际体积取决于模型，压缩可能影响细节。压缩内存超限时请使用标准 PLY；当前 SPZ 编码器还存在约 ±2048 场景单位的坐标范围限制。

#### 预览导航与相机修复
- 新增水平 WASD 漫游，方向随相机水平朝向变化，不再随俯仰升降。 
- 漫游速度随缩放调整，支持 Shift 三倍加速，仅在透视视图生效。 
- 新增“自动定位视角”，返回首张有效训练图片的相机视角；全景使用最早已注册画面的 front 面。 
- 从三视图点击自动定位，也会直接切换至训练参考透视视角。 
- 点击自动定位后即可直接使用 WASD，无需再次点击画布。 
- 修复连续放大后右键平移过快、三视图旋转跳变及正交网格裁剪问题。 

没有可靠训练相机的项目会禁用自动定位，不会用猜测视角代替。

#### 图片顺序确认
- 普通和全景图片超过100张时，生成前询问是否已按拍摄顺序排列。 
- 已排序使用顺序匹配；未排序或100张及以下使用穷举匹配。 
- 顺序选择会保存到任务中，重试和续跑不再询问。 
- 自动队列等待确认，不跳过当前任务；取消确认会关闭队列。 

建议文件名顺序与拍摄顺序一致，并确保相邻图片有足够重叠。

#### 检测、进度与兼容性
- 素材类型检测使用轻量元数据读取，切换质量档位不再重复检测。 
- 改进多轮特征提取、匹配和重建的进度展示，区分真实计数与阶段完成率。 
- 全景六面准备与实际训练统一归入“Splat 训练”，不再将六面图片数当作训练步数。 
- 改进运行监控状态更新，补充匹配活动和长时间无输出提示。 
- 为已确认受影响的 PNG/XMP 分数焦距读取增加临时兼容补丁，不修改图片或元数据。 
- 修复 Rust 1.99 Clippy 检查导致的 CI 失败。 

### 💻 平台支持
- **Windows 11 x64** 
- **macOS 15\+ Apple Silicon Alpha**：M1 及更新芯片，未签名、未公证。 
- **Ubuntu 24.04 x86\_64 Alpha** 

COLMAP 可按平台和设备条件使用 GPU 或 CPU；Brush 训练仍需要可用的图形处理后端。

### 📦 安装包
- Windows：`OOOSplat\-0.7.0\-x64\-windows.exe` 
- Apple Silicon macOS：`OOOSplat\-0.7.0\-arm64\-macos.dmg` 
- Ubuntu 24.04：`OOOSplat\-0.7.0\-x64\-linux.deb`

## English

OOOSplat 0.7.0 adds panorama video and image generation, external model import, multi\-format export, horizontal WASD navigation, and Auto locate view, with improvements to image matching, progress reporting, and camera controls.

### ✨ Highlights

#### Panorama Video and Images
- Supports stitched, monoscopic, full 360°×180°, 2:1 ERP MP4. 
- Accepts folders containing at least two same\-sized JPG, JPEG, or PNG panoramas. 
- Detects media types automatically; uncertain inputs require an ordinary/panorama choice in the media box. 
- Reconstructs full panoramas before converting registered images into six\-face training data. 
- Uses dedicated training recipes. With Auto Optimize disabled, Fast / Balanced / Detailed cap splats at 1 / 2 / 3 million. With it enabled, quality and VRAM determine the cap, up to 10 million. 

Caps do not guarantee achieved counts or sufficient VRAM. Dual\-fisheye, stereo, VR180, cropped panoramas, private camera originals, and panorama reshoots are unsupported.

#### External Model Import
- Import a file or folder from the Completed group. 
- Supports standard/compressed PLY, SOG, SPZ, SPLAT, and KSPLAT. 
- Detects associated COLMAP data and enables eligible reshoot tasks. 
- Reuses existing preview, editing, and export tools. 
- External files remain read\-only and are not deleted when removing the imported project. 

COLMAP\-only projects, ordinary point\-cloud PLY, 2DGS, LCC/LCC2, and Streamed SOG are unsupported.

#### Multi\-format Export
- Choose standard PLY, compressed PLY, SPZ v4, or bundled SOG directly from Export. 
- Format descriptions appear in the menu, without a second selection dialog. 
- Removes the complete intermediate PLY and processes edits on demand. 
- Shows progress, output size, and location, with cancellation and retry support. 
- Supports portrait/landscape video and standalone offline HTML. 
- Preserves the original `final.ply` and existing exports on failure or cancellation. 

SOG and SPZ are typically smaller, but size varies and compression may affect detail. Use standard PLY when compression exceeds the memory budget. The current SPZ encoder also has a coordinate range of approximately ±2048 scene units.

#### Preview Navigation
- Horizontal WASD movement follows camera heading without changing elevation with pitch. 
- Zoom\-relative speed, Shift ×3 acceleration, perspective views only. 
- Auto locate view restores the first valid training camera; panorama projects use the earliest registered image's front face. 
- Locating from a fixed orthographic view returns directly to the reference perspective view. 
- WASD works immediately after locating, without another canvas click. 
- Fixes excessive post\-zoom panning speed, fixed\-view rotation jumps, and orthographic grid clipping. 

Locating is disabled when no reliable training camera is available.

#### Image\-order Confirmation
- More than 100 ordinary or panorama images require capture\-order confirmation before starting. 
- Ordered sets use sequential matching; unordered sets and sets of up to 100 images use exhaustive matching. 
- The strategy persists for retries and resumes. 
- Automatic execution waits for confirmation; cancelling disables the queue without skipping the task. 

Keep filename order consistent with capture order and provide sufficient overlap between neighboring images.

#### Detection, Progress, and Compatibility
- Lightweight metadata detection is reused when changing quality. 
- Improves multi\-pass COLMAP progress and distinguishes result counts from completion percentages. 
- Keeps panorama preparation and actual training under Splat Training, without treating face counts as training iterations. 
- Improves runtime\-monitor updates and matching activity/silence messages. 
- Adds a narrowly scoped temporary workaround for the confirmed PNG/XMP rational focal\-length parsing issue, without changing image bytes or metadata. 
- Fixes CI failures caused by Rust 1.99 Clippy checks. 

### 💻 Platforms
- **Windows 11 x64** 
- **macOS 15\+ Apple Silicon Alpha**: M1 or newer; unsigned and unnotarized. 
- **Ubuntu 24.04 x86\_64 Alpha** 

COLMAP uses GPU or CPU as supported. Brush training still requires an available graphics backend.

### 📦 Packages
- Windows: `OOOSplat\-0.7.0\-x64\-windows.exe` 
- Apple Silicon macOS: `OOOSplat\-0.7.0\-arm64\-macos.dmg` 
- Ubuntu 24.04: `OOOSplat\-0.7.0\-x64\-linux.deb`

# OOOSplat 0.6.1

[中文](https://github.com/ooolabdev/ooosplat/releases#%E4%B8%AD%E6%96%87) \| [English](https://github.com/ooolabdev/ooosplat/releases#english)

## 中文

OOOSplat 0.6.1 加入版本更新提醒、场景操作轴、反选快捷键和视角恢复，并改进预览排序、编辑保存、闭环检测及运行性能。

### ✨ 主要更新

#### 版本更新提醒
- 启动后自动检查是否存在适用于当前平台的新版本。 
- 发现新版本时显示发布日期和更新说明。 
- 支持复制 GitHub 和夸克网盘下载地址。 
- 忽略弹窗后，仍可从主界面或设置中的“版本更新”重新查看。 
- 更新检查失败不会影响生成、预览或其他功能。 
- OOOSplat 仅提供更新提醒，安装包仍由用户手动下载和安装。 

#### 场景操作轴

变换模式加入移动轴和旋转环：
- 可以直接在场景中拖动模型，调整位置和角度。 
- 移动轴和旋转环可在右侧变换面板中切换。 
- 再次点击当前工具即可关闭操作轴。 
- 模型旋转以模型中心为轴心，减少旋转时的位置漂移。 
- 场景操作与右侧数值面板保持同步。 
- 每次拖动只生成一条撤销记录，并继续使用自动保存。 
- 操作轴不会写入 PLY、视频或 HTML 导出结果。 

#### Gaussian 选择与编辑
- 矩形选择、球形选择和盒形选择均支持反选。 
- 可以使用 `Ctrl\+I`，macOS 使用 `Command\+I`，快速反转当前选区。 
- 矩形选择会判断 Gaussian 的可见范围，不再要求 Gaussian 中心点必须位于选框内。 
- 调整了预览操作按钮样式和操作提示。 

#### 视角恢复与预览排序
- 重新打开项目时恢复上次保存的视角。 
- 修复恢复视角后必须移动相机，Gaussian 排序才会正常的问题。 
- 模型变换、裁切和删除结果会在首次排序前恢复。 
- 改进连续旋转、切换项目和重新进入预览时的排序稳定性。 
- WebGPU 和 WebGL2 使用相同的恢复流程。 

视角保存在当前设备上，不会跟随项目文件迁移到其他设备。

#### 保存编辑与导出 PLY
- “保存”按钮调整为“保存编辑”，用于保存编辑结果和当前视角。 
- 自动保存继续保留。 
- 保存编辑不会生成 `edit.ply`。 
- “导出”菜单增加“导出 PLY”，需要时可单独生成或更新 `edit.ply`。 
- 原始 `final.ply` 不会被覆盖。 
- 正常退出预览或进入动画模式时，会先保存剩余编辑和视角，不再询问是否生成 PLY。 
- 保存失败时保留当前编辑状态，用户可以直接重试。 

#### 自动优化与闭环检测

开启自动优化后，快速、均衡和精细三个档位都会为视频顺序匹配启用闭环检测：
- 帮助识别绕拍视频中相隔较远但内容相同的画面。 
- 改善环绕拍摄首尾衔接不足造成的漂移。 
- 关闭自动优化后仍使用原有匹配方式。 
- 图片序列、高清补拍和桥接补帧的匹配流程保持不变。 

闭环检测会增加部分匹配时间，也不能保证所有素材都能找到有效闭环。

#### 任务界面与效果统计
- 改进任务状态、日志和进度的界面更新方式，减少生成期间的界面负担，避免因刷新过于频繁而出现白屏。 
- 修复 Planner 效果统计记录器未正确连接的问题。 
- 普通生成、续跑和高清补拍可以记录实际使用素材、注册图像、三维点、Splat、PLY、桥接补帧和 Brush 配置。 
- 失败任务只记录已经取得的结果，不会将尚未执行的数据填写为零。 
- 取消任务不会发送 Planner 终止统计。 
- 历史任务不会自动补报旧数据。 

### 💻 平台支持
- **Windows 11 x64**：COLMAP 支持兼容的 NVIDIA GPU，并可在需要时使用 CPU。Brush 训练仍需要可用的图形处理设备。 
- **macOS 15\+ Apple Silicon Alpha**：支持 M1 及更新芯片，当前版本未签名、未公证。 
- **Ubuntu 24.04 x86\_64 Alpha**：内置固定版本的 COLMAP 和 Brush。 

### 📦 下载

OOOSplat 0.2.0

OOOSplat 0.2.0 新增 Windows COLMAP CUDA GPU 自动加速，并首次提供 Apple Silicon macOS 与 Ubuntu 24.04 安装包。本版本还更新了应用品牌、桌面图标、开源许可与项目文档。
与 0.1.0 相比，核心生成流程和项目目录结构保持兼容，无需手动选择 COLMAP 的 CPU/GPU 模式。

下载与平台支持
- Windows 10/11 x64：OOOSplat\_0.2.0\_x64\-setup.exe 
- macOS 15\+ Apple Silicon Alpha：OOOSplat\_0.2.0\_arm64.dmg 
- Ubuntu 24.04 x86\_64 Alpha：OOOSplat\_0.2.0\_amd64.deb
macOS 与 Ubuntu 版本目前属于 Alpha。其他 macOS、Linux 版本及 CPU 架构尚未验证。 

主要更新
Windows：COLMAP GPU 自动加速
- 内置支持 CUDA 的 COLMAP。 
- 启动应用和任务开始前自动检测 NVIDIA 显卡。 
- 自动检查 NVIDIA 驱动版本与 Compute Capability。 
- 满足要求时，自动使用 GPU 加速特征提取和顺序匹配。 
- 不满足要求或检测失败时自动回退 CPU，不会阻止任务运行。 
- 界面显示当前使用 GPU 或 CPU，以及未启用 GPU 加速的具体原因。 
- 多显卡环境自动选择兼容性最好的设备。 
- 无需安装 CUDA Toolkit，也无需手动选择 CPU/GPU。 

GPU 加速最低要求：
- NVIDIA Windows 驱动 528.33 或更高 
- Compute Capability 5.0 或更高
COLMAP Mapper 仍使用 CPU。Brush 的 GPU 检测和运行机制独立于 COLMAP。
相关改动：[PR \#7](https://github.com/ooolabdev/ooosplat/pull/7) 

Apple Silicon macOS Alpha
- 首次提供原生 Apple Silicon .dmg 安装包。 
- 支持 M1 或更新的 Apple Silicon Mac。 
- 当前最低支持 macOS 15。 
- 内置 arm64 FFmpeg、FFprobe、COLMAP CPU 版和 Brush。 
- 无需安装 Homebrew，也不依赖系统 PATH 中的同名工具。 
- COLMAP 当前固定使用 CPU。 
- Brush 使用可用的 Metal 图形后端。 
- 已在 MacBook Air M2 上完成从视频导入到 final.ply 生成的完整链路测试。
当前安装包尚未进行 Apple Developer 签名和公证。首次启动时如果被 Gatekeeper 拦截，请在 Finder 中右键 OOOSplat 并选择“打开”。
相关改动：[PR \#8](https://github.com/ooolabdev/ooosplat/pull/8) 

Ubuntu 24.04 Alpha
- 首次提供 Ubuntu 24.04 x86\_64 .deb 安装包。 
- 提供桌面 GUI 和无界面 CLI 能力。 
- 安装包内置固定版本的 Brush。 
- FFmpeg、FFprobe 和 CPU 版 COLMAP 由 Ubuntu 软件源提供。 
- 安装 .deb 时，APT 会自动解析并安装所需的系统依赖。 
- Brush 可使用 NVIDIA、AMD 或 Intel 支持的图形后端。 
- 当前端到端生成测试主要覆盖 NVIDIA GPU；AMD、Intel 和纯软件图形后端仍需要更多测试。
安装命令：
sudo apt install ./OOOSplat\_0.2.0\_amd64.deb
安装 Ubuntu 版本时需要能够访问系统软件源。当前版本不代表已经支持 Ubuntu 22.04、其他 Linux 发行版或 ARM64 Linux。
相关改动：[PR \#10](https://github.com/ooolabdev/ooosplat/pull/10) 

进度与耗时改进
- “总耗时”现在独立实时更新。 
- 即使 Brush 长时间没有输出日志，耗时仍会持续增加。 
- 任务完成、失败或取消后固定显示最终耗时。 
- 新任务不会继承上一次任务的计时状态。 

品牌与应用图标
- 使用新的 OOOSplat 三环 Logo。 
- 更新应用内 Logo、README Logo及桌面应用图标。 
- Windows 桌面快捷方式、任务栏、程序 EXE 和安装程序使用新图标。 
- Windows 和 macOS 图标调整为更符合系统风格的圆角设计。 
- 左上角 OOOSplat 字标改为简洁的无衬线字体。

开源许可与文档
