## 现在可以使用

- 本地网页里的三维房间环绕、缩放和键盘平移（先点画布，WASD / 方向键）。
- 独立物品选取、拿起观察、拖动旋转、精确归位。
- 抽屉滑动、柜门旋转；抽屉里的书跟随父物品。
- Spark 2.3.1 高斯渲染，导入 Gaussian PLY / SPZ / SPLAT / KSPLAT 与内嵌贴图 GLB。
- 编辑名称、位置、角度、统一缩放、父物品和简单关节。
- 保存包含模型和记忆附件的项目包到移动硬盘，并在下次打开时恢复；保留各次保存的历史快照。
- 导入/导出可移植 `.room.zip` 项目包。
- 带检查的数据转换工具：明确相机坐标、RGBA 物品和背景排除蒙版。

**演示房间中的家具是程序生成的网格，花器是程序生成的 14,080 个高斯。两者都不是实际扫描成果。** 当前可以处理本项目手机采集器导出的采集包，生成静态空间；尚未实现真实物品自动分离。

## 打开

在 Finder 中双击 **启动工作台.command**。或者在项目目录运行：

```sh
npm run dev
```

打开 `http://127.0.0.1:4317/`。服务器只监听本机。关闭运行它的终端会停止服务；停止服务、退出项目程序后再弹出移动硬盘。

首次在另一台有 Node.js 22.12+ 的电脑上运行，先 `npm ci`。依赖缓存位置为项目内 `.cache/npm`，不需要云端账号。构建用 `npm run build`，本地构建预览用 `npm run preview`。直接双击 HTML 不会运行本地保存接口。

## 先试这几步

1. 选择“高斯花器”，点击“拿起观察”，在中间拖动旋转，再“放回原处”。
2. 选择“上层抽屉”，拖动行程；选择“抽屉里的书”，检查可单独观察与归位。
3. 打开“左侧柜门”，测试旋转。
4. 点击“保存到硬盘”，刷新网页，确认开合状态仍在。
5. 有真实扫描模型后，新建空场景，先导入固定背景，再导入独立物品。

导入模型保留原始坐标，通过所选单位换算尺度，不再按 45 厘米归一化；现有背景里的物品不会因导入独立物品而自动消失，需要在重建背景时排除。

## 目录

```text
apps/viewer/          网页、Spark 渲染与本地文件保存
packages/scene/       场景格式、关节、观察归位和项目包
tools/dataset/        相机与蒙版转换；实验性 Stera MCAP 提取
tools/generate_demo.py 原创合成高斯样本生成器
data/raw/            原始录制，保留原件
data/processed/      分割、转换、训练输出
data/projects/       当前项目和上一版本，包含模型，不提交 Git
docs/                架构、采集约定、接入来源和开发状态
artifacts/qa/        浏览器验证与截图
```

“保存到硬盘”现在写入 `data/projects/library` 的新快照，并更新 `current-pointer.json`；旧 `current.room.zip` 和 `previous.room.zip` 保留。浏览器“导出备份”使用浏览器的下载位置，可自行选择移动硬盘。
