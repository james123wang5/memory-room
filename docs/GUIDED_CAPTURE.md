# 引导采集 v0.3：先把反馈放到扫描过程中

2026-10-15。用户要求先写好代码并安装，由用户实拍验证，再调整规则。当前参数是第一版启发式阈值，**不能宣称已保证全屋高质量复刻**。

## 产品流程

手机引导扫描 → 手机采集预检 → 导出 `.capture.zip` → 网站“导入手机采集” → 本机自动预检、重建、留出视角检查 → 通过后由用户打开结果。

不需要 GPT 或 Codex 手工挑帧、转换格式、反复调参。重建本身仍然需要 GPU 和计算时间；当前路线在用户的 Apple Silicon Mac 上本地运行，不是无 GPU 浏览器直接训练。

## 手机已经写入的反馈

- RoomPlan 与采集共用 ARSession，识别墙面、地面并接收距离、速度、照明、纹理指令。
- 在相机画面直接显示当前提醒和下一补扫点方向；明显问题配合触觉提示。
- 根据相机速度、转动、曝光时间估计运动模糊；检查亮度、过曝、边缘信息、有效深度和相邻视角深度衔接。
- 排除不合格帧和重复位置，显示有效关键帧，不再录够数量就算成功。
- 用 0.5 米左右的结构表面格记录不同观察位置。红点待扫、橙点观察不足、绿点表示至少三次观察且有基线和视角变化。
- 深度不一致时不把后方墙标绿。跨位置反复确认被前景遮挡的格子标灰，从可见覆盖分母排除；这些灰色区域没有被还原承诺。
- 房间完成还要求结构识别、可见多角度覆盖、足够朝向、移动路线、回到起点，以及用户确认已走遍可到达区域。
- 可以只导出房间，不强制登记物件。“重扫本阶段”会保留旧图像，旧片段改为 `discarded:…`，不再进入当前房间训练。
- 物品阶段先确认放稳；绕拍方向不足时不能完成。空位阶段先确认物品和手已经移开。

绿色和百分比只表示**识别到的结构表面**达到观察条件，不代表家具背面、柜内、反光区域或所有未知表面已完整扫描。当前没有自动识别手持物体的完整运动，也没有完成物品分割与独立重建。

## 网站自动处理

`tools/capture_jobs.ts`：本机单任务队列，流式保存采集包，状态轮询、取消和结果下载。单包上限 1 GB，原件在 `data/raw/capture-imports/`，处理产物在 `data/processed/jobs/<id>/`。不自动覆盖当前空间；只有 `ready` 状态允许下载成片包。

`tools/automatic_reconstruction.py`：安全解包 → `quality.py` 复核真实来源、质量记录、路线与覆盖 → 自动导出数据 → LiDAR 初始化 → Brush 快速重建 → 自动细化 → 留出视角画面检查 → 项目打包。

`quality.py`：旧版没有引导记录的包、演练包、缺深度或未通过手机预检的包不会自动成为成片。最终用每第十个留出视角作 RGB 比较；当前平均 PSNR 23 / 最差 17 是实验门槛，不是行业认证或视觉质量保证。无法验收的结果显示补扫信息，保存诊断，不静默标成功。

任务状态：`importing → checking → preparing → training → evaluating → ready`，或 `needs_rescan / failed / cancelled`。

## 需要用户实拍验证的内容

1. RoomPlan 和原始图像/深度录制共用 ARSession 后，真实设备上是否持续提供正常深度和结构回调。
2. 红点、方向、遮挡判断是否准确，是否有永远扫不绿的位置。
3. 速度、模糊、暗光、纹理门槛是否过于严格或漏检。
4. 一次真实引导房间采集导入后，自动训练的画面是否符合预期。尚无新版引导采集的完整成功成片样本。
5. 反光、低纹理、遮挡、家具表面的完整程度。当前结构覆盖不能证明这些问题全部解决。

## 研究来源

- [Scaniverse 使用指南](https://scaniverse.com/support)：多角度移动、扫描时用模糊逐渐变清晰的反馈找补扫区域。公开资料没有给出其完整重建和质量引导源码，没有复制其算法。
- [Apple RoomPlan](https://developer.apple.com/augmented-reality/roomplan/) 与 [WWDC 讲解](https://developer.apple.com/videos/play/wwdc2022/10127/)：实时结构、原生扫描引导与速度/距离/照明/纹理指令。SDK 源码不开放，本项目调用系统公开接口。
- [Polycam 室内采集指南](https://learn.poly.cam/hc/en-us/articles/48339214285844-How-to-Capture-High-Fidelity-Interior-Scans-in-Object-Mode)：周边、中圈、细节三遍及连续衔接。该指南描述 Object Mode 的室内摄影测量，不能把其中的重叠比例直接当成高斯成片保证。
